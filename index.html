Quick Start

Drop in two files and you're ready to go.

<!-- 1. Link the stylesheet -->
<link rel="stylesheet" href="powerkit.css" />

<!-- 2. Add the script before </body> -->
<script src="powerkit.js"></script>

That's it. Every component on this page is built exclusively with powerkit.css and powerkit.js.
